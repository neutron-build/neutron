# @neutron-build/otel

OpenTelemetry integration for Neutron.

Automatic tracing and metrics for Neutron routes, loaders, and actions.

## Installation

```bash
npm install @neutron-build/otel
```

## Usage

```typescript
import { otelMiddleware } from "@neutron-build/otel";
```
