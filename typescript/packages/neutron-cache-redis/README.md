# @neutron-build/cache-redis

Redis cache provider for Neutron.

Redis-backed caching with serialization and tag-based invalidation.

## Installation

```bash
npm install @neutron-build/cache-redis
```

## Usage

```typescript
import { createRedisCacheStore } from "@neutron-build/cache-redis";
```
