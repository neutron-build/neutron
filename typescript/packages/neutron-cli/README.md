# @neutron-build/cli

Build tool for Neutron TypeScript projects.

Dev server, static site generator, and production builder for Neutron apps.

## Installation

```bash
npm install @neutron-build/cli
```

## Usage

```bash
neutron-ts dev      # Start dev server with HMR
neutron-ts build    # Build for production
neutron-ts preview  # Preview production build
```
