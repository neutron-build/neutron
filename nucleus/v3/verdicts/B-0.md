# Defects (fix before merge)

1. **The qdrant keep-alive client measures TCP mechanics, not Qdrant (new, blocking).** `http.rs::Connection::request` writes the request head and body in two separate `write_all` calls and never sets `TCP_NODELAY`: classic Nagle + delayed-ACK, ~40 ms per query. Evidence from the live row: pass metrics p50 44.07 ms / p99 49.05 ms → 22.47 qps = exactly 1000/44.4 ms, uniformly across cold and warmup; three single-write probe requests of my own to the same collection on the same running container returned in **1.6–1.9 ms** with identical results. The pgvector arm does ~1411 qps at ef=16; committing a ~22 qps qdrant would poison every §5.3 vector ratio. The in-flight qdrant row (and any of its result commits) must be discarded after the fix — single buffered write per request and/or `set_nodelay(true)`, plus a latency sanity check that per-query p50 is in the low milliseconds. Note the irony: this defect was introduced by the fix for round-1 finding 5 (the arms are still not overhead-matched).
