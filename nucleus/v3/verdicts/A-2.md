- **RW-1** (`row_i_integrity`, after case (e), at every size and kind). Every bit of each field `verify` compares:

  - **(e2)** the reference epoch flipped in one bit;

- **RW-2** (`map_page_codec`, bad list). The header id flipped in each of its 64 bits, re-sealed: `check_map_page` must be `Corrupt`.
