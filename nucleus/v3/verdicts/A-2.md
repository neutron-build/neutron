### The seven equivalents

- **ISPL-LEN-TOP** (`len & !(1 << 63)`). A slice's length is at most `isize::MAX`, so bit 63 is always 0.
- **ISPL-LEN-U32** (`len as u32`). It differs only for a slice of 2^32 bytes or more whose length mod 2^32 is a page size. No store page is one, no test can practically allocate one, and on wasm32 `usize` is 32 bits, so there it is exact. Equivalent in practice, and not testable in the suite.
- **RO-CHK-TOP** (`i & !(1 << 63) >= f`). An `i` with bit 63 set gives `16·i`, which overflows `usize` on a 64-bit target (and `usize::try_from` fails on 32-bit), so `ref_offset` is still `None`.
- **RO-IDX-U16** (`usize::try_from(i & 0xFFFF)`) and **RE-F-U16** (`usize::try_from(f & 0xFFFF)`). Both run after `i < f ≤ 4094`, or on `f ≤ 4094 < 2^16`.
- **CM-ID-RHS-TOP** (`h.id != id & !(1 << 63)`). `id` is `position_id(Radix::Map, …)`, whose bit 63 is always 0.
- **CM-LEN-BOTH-U16** (lengths compared mod 2^16). `geom.page_size` is an allowed size, and `read_header` refuses every other length. The allowed sizes are distinct mod 2^16: 4096, 8192, 16384, 32768 and 0.
