## Substance

**Root-table correctness by lifecycle.** The design is sound; the defects are in the test text and two gaps in the written argument.
- *Create.* The entry is installed after the root page is initialised, under the new root's exclusive latch and the directory leaf's. A reader that sees it either fails `try_latch` (retry) or is granted after CreateTree's release, so it sees an initialised root. Restarts precede the allocation, so no installed entry is rolled back.
- *Drop.* Step 1 changes the state; a reader that read `live` re-reads `dropping` under the latch, the compare fails, and step (1) then stops it. The last step removes the entry under the root's exclusive latch before the free; the state compare masks the order for every `live`-needing reader, so the order matters only to a namer that accepts `dropping` (see R1).
- *Recreate / LPID reuse.* Tree ids are never reused and the root LPID of an entry never changes (I-ROOT-STABLE), so an entry goes absent → `live(r)` → `dropping(r)` → absent with no ABA; even a torn read of the tuple cannot mix two LPIDs. Comparing (root LPID, kind, state) is exact. No global gen is needed (C3 holds).
- *Moved root.* Does not exist apart from drop-then-reuse (I-ROOT-STABLE). Correct.
- *Crash and rebuild.* Built from image `k`'s directory before replay, maintained by replayed CreateTree / DropTree state changes, walks resumed at step 6 through normal operation; read-only open the same. Sound.
- *Concurrent DDL.* Directory changers on one leaf serialise on it exclusively; the table write happens inside that hold. Sound.
- *Revalidation catches every stale case* — in substance yes, but the written proof covers only the same-frame case (R3), and the pre-validation header check has no stated outcome (R2).

**C2.** The unmapped-pin retry is stated, the header-only rule is stated, cases C and D are in the test. A first latch on another tree's page is harmless in the interim: it is `try_latch` and the thread holds nothing else. Naming it as an exception to "one tree" is -F4b's (its G4), correctly deferred. Gap: R2.
