## Findings

1. **The -z deviation is accepted.** Work step 1 names `-z` with NUL parsing
   as an allowed alternative, and it is the stronger choice:
   core.quotePath=false still C-quotes `"`, `\` and control bytes, which the
   new docs/a"b.md scenario proves. All four path listings the card names now
   use -z: changed(), the tip diff-tree, check-core-paths and the runner's
   diff and status. Every reader is NUL-aware (`read -r -d ''`,
   `mapfile -d ''`, split on "\0"). The runner also no longer folds git's
   stderr into the path list or splits on whitespace, so paths containing
   spaces now work. A side effect: spikes/ü.txt, which an S card was wrongly
   refused before, now merges.
2. **The adapted named mutant is faithful.** Dropping -z from changed() is the
   real equivalent of dropping core.quotePath=false. It fails 12 scenarios,
   including the card's named docs/é.md one. Restoring the original newline
   changed() and reader fails exactly the three quoted-path scenarios. The S
   scenario on scripts/é.sh still passes under that mutant, which is correct:
   for S tiers a quoted path falls back to the "outside nucleus/v3, needs P"
   rule.

   one file, and it is the verdict) is correct. The count guard, though, is

   code and merged under TIP-COUNT. Since that probe would merge an
