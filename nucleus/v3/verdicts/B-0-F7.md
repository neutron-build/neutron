# Findings

1. **(blocks C1 → B-0-F7-F1) The recorded row is honest but not reproducible.** Same commit, script, client, data digest and quiet host:

   | ef | committed qps / p50 ms / recall@10 | gate re-run qps / p50 ms / recall@10 |
   |---|---|---|
   | 16 | 2404 / 0.344 / 0.9410 | 427 / 2.264 / 0.9352 |
   | 64 | 664 / 1.566 / 0.9951 | 309 / 3.206 / 0.994 |
   | 256 | 278 / 3.666 / 0.9992 | 182 / 5.585 / 0.999 |

   Both inits ended "green, 8 segments". The worker's run had 1,000,000 vectors indexed; mine had 984,064, and at ef16 its server p50 was 1.8 ms against the worker's 0.21 ms. A fresh build can therefore land in at least three index states (wedged at 92 segments, about 98% indexed, 100% indexed), and the current readiness rule cannot tell them apart. The worker's run also jumps 4x between ef32 (0.38 ms) and ef64 (1.56 ms), against 1.2x in mine. That suggests the state can also change across the per-series cold restarts. This is unverified because the row records index state only at init. **P judgement on arm 2:** the 10 ms limit stays (it caught a real wedged index). The fix is a deterministic index state, which is new work for B-0-F7-F1.
2. **The chain7 inference is wrong, but the explanation still holds.** The diagnosis infers that chain7's collection "had settled". However, chain7's 1.6–1.9 ms probes match the about-98%-indexed state measured here (server ≈ 1.8 ms), not the fully indexed one (0.22 ms). The recall shift is still explained by index state; only which state chain7 had is unknown.
3. **Release client in the re-measure goes beyond what the rule licensed.** Arm 1 did not fire, so Work 5 ("chain10's script") did not authorise a client change. It is immaterial to pass/fail. It does matter to the recorded numbers: about 0.4 ms of debug-client overhead on a 0.34 ms p50. The anomaly line and README disclose it. The client build should become a harness-wide rule recorded in provenance (folded into F1).
4. **(→ B-0-F7-F2) The command glue that fills the server column is untested.** M1b, O4 and O7 all pass 113/113. The card's mutant rule ("tests or checks") is met by the parse-seam test and by the live awk catch. The committed evidence is unaffected: I verified the CSVs independently.
