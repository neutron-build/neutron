## Blockers (rework on this card; no new card)
**R1. `$HOME` read-only is bypassed by the inherited cwd.** `Popen(cwd=wt)` sets the cwd before stage 2's mounts, and CONTAIN_SETUP never re-enters it, so the cwd stays on the mount underneath the read-only bind. `..` from there reaches every directory below `$HOME`'s own mountpoint, which today means all of `~/.cache`: other cards' worktrees and targets, review evidence, `~/.cache/opencode/node_modules`.
- Measured: a committed `esc.sh` as an Acceptance line wrote `~/.cache/nv3-cards/.gate-acc-escape`, runner `pass: true`. An absolute path to the same file gets EROFS. `~` itself is still read-only by this route (it crosses onto the bind).
- opencode's tool shells did not have it: no `/proc/*/cwd` was writable from there. But a tool shell and an Acceptance line are not the same trust, and Acceptance runs the worker's code.
- Fix: `cd -P -- "$PWD"` after the masks, in both setup copies, and a row that writes `../x` from an Acceptance line. Spiked: refused, `/proc/1/cwd/..` too.

**R2.
