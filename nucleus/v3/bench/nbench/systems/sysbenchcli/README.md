# sysbench 1.0.20 client container

Client-side load generator for row `oltp-sysbench-pg17`. Built locally
(`nbench-sysbenchcli:local`) from the pinned alpine base; sysbench comes
from Alpine's community repository with the PostgreSQL (`pgsql) driver
verified during image build.
